# Finance & Expense Analytics

## Project Overview

This project focuses on analyzing company expenses and monitoring budget performance using Microsoft Excel and Power BI. It helps identify spending patterns, budget overruns, and payment-wise expenses.

## Project Objectives

* Analyze total company expenses.
* Compare actual expenses with budgets.
* Identify over-budget transactions.
* Analyze expenses by department, vendor, and payment method.
* Create an interactive Power BI dashboard.

## Tools Used

* Microsoft Excel
* Power BI
* Power Query

## Key Findings

* Total transactions: 500
* Over-budget transactions: 212 (42.4%)
* Within-budget transactions: 288 (57.6%)
* Overall budget utilization: Approximately 97%
* Highest payment-wise expense: Bank Transfer
* Highest vendor-wise expense: Tata Power

## Dashboard

The interactive Power BI dashboard includes KPI cards, charts, and slicers to explore expense data.

## Conclusion

This project demonstrates how Excel and Power BI can be used to analyze financial data, monitor budgets, and present business insights through an interactive dashboard.
